# Telecommunications MATLAB Exercises

This repository contains MATLAB exercises for the course **Telecommunication Systems I**.  
The projects focus on digital communication systems, pulse shaping, spectral analysis, modulation, detection, and error probability estimation.

## Repository Contents

### 1. SRRC Pulse and 2-PAM Baseband Simulation

A MATLAB project focused on SRRC pulse properties and their use in a 2-PAM baseband transmission system.  
It includes time-domain pulse plots, energy spectral density analysis, practical bandwidth estimation, pulse orthogonality checks, pulse shaping, and matched filtering.

### 2. PAM Signal PSD Analysis

A MATLAB project for analyzing the spectral behavior of 2-PAM and 4-PAM baseband signals.  
It includes SRRC pulse generation, waveform construction, periodogram-based PSD estimation, theoretical PSD comparison, and the study of how the symbol period affects bandwidth.

### 3. 16-QAM Communication System Simulation

A MATLAB simulation of a complete 16-QAM digital communication system using two independent 4-PAM branches.  
It includes Gray-coded symbol mapping, SRRC pulse shaping, carrier modulation, AWGN channel modeling, coherent demodulation, matched filtering, symbol detection, and Monte Carlo SER/BER analysis.


## Notes

The reports included in each folder explain the theory, methodology, figures, and conclusions for the corresponding exercise.
